ABOUT THE PROJECT

What is Phishing Website Detection?

🎯

Project Objective

The main objective of this project is to identify suspicious website URLs that may be associated with phishing attacks. The system analyzes different characteristics of a URL and calculates a risk score.

🧠

Why Phishing Detection?

Phishing websites are designed to trick users into revealing sensitive information such as usernames, passwords and financial details. Detecting suspicious URLs can help users avoid potentially harmful websites.

💻

Technology Used

This project uses Python and Flask for the backend, HTML and CSS for the user interface, and rule-based URL analysis techniques for phishing detection.

SYSTEM PROCESS

How It Works

The system follows a simple step-by-step URL analysis process.

01

Enter URL

The user enters the website URL that they want to check.

02

Analyze URL

The system checks the URL for suspicious characteristics and security indicators.

03

Calculate Risk

Suspicious characteristics increase the overall risk score.

04

Display Result

The system displays Low, Medium or High risk along with the reasons.

DETECTION FEATURES

What Does The System Check?

🌐

IP Address

Detects URLs using an IP address instead of a normal domain name.

🔒

HTTPS

Checks whether the website uses a secure HTTPS connection.

🔑

Suspicious Words

Looks for words such as login, verify, account and password.

🔗

URL Structure

Checks URL length, subdomains and suspicious symbols.

📎

URL Shorteners

Detects commonly used URL shortening services.

📊

Risk Score

Combines detected indicators into an overall risk score.
